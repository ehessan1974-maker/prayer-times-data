# بيانات قاموس المورد والمصطلحات المتخصصة

بيانات بحث القاموس لتطبيق «مواقيت الصلاة والمترجم» — تُجلب من هذه القنوات:
- `https://cdn.jsdelivr.net/gh/ehessan1974-maker/prayer-times-data@main/...` (أساسي)
- `https://raw.githubusercontent.com/ehessan1974-maker/prayer-times-data/main/...` (بديل)

## البنية
- `d/<مجموعة>/<حرف>.txt` — إنكليزي ← عربي (سطر لكل مدخل: `الكلمة<TAB>المعاني`)
- `r/<مجموعة>/<حرف>.txt` — عربي ← إنكليزي (فهرس عكسي)
- `manifest.json` — الإصدار وعدد مداخيل كل مجموعة

## المجموعات
| المعرّف | المحتوى | المداخيل |
|--------|---------|----------|
| gen | المورد الحديث (إنكليزي←عربي، معاني كاملة بأمثلة) | ~61,800 |
| med | المعجم الطبي الموحد + الصيدلة + التشريح + جسم الإنسان + بيطري | ~141,000 |
| sci | العلمي والفني والهندسي + معلوماتية + رياضيات وفلك + أحياء + جيولوجيا + إحصاء | ~120,000 |
| phy | الفيزياء العامة والنووية (الموحد + مجمع دمشق) | ~10,000 |
| che | الكيمياء (الموحد + مجمع دمشق) | ~8,400 |
| eng | مدنية + كهرباء + IEC + سيارات + طيران وفضاء + مياه + طاقة + نفط + نقل | ~81,000 |
| law | القانون + المسرد القانوني + الملكية الفكرية + العقود | ~6,000 |
| lit | اللغة والأدب + اللسانيات + مسرح + بلاغة وعروض (الشعر) | ~4,600 |

العكسي العربي←إنكليزي متاح للمجموعات: med، phy، che، law، lit.

## المصادر والحقوق
جُمعت الرقمنةُ من قاعدة بيانات مشروع [arabterm / Wiki Term Base](https://github.com/forzagreen/arabterm) المفتوح، والمصادر الأصلية:
- **المورد الحديث** (2008) — دار العلم للملايين (Librairie du Liban)
- **المعاجم الموحدة** — ألكسو / مجمع الملك عبدالله (الطب، القانون، الصيدلة، الفيزياء، الكيمياء، الرياضيات والفلك، الأحياء، الجيولوجيا، الأرصاد، البحار، الوراثة، النفط، المعلوماتية…)
- **معاجم مجمع اللغة العربية بدمشق** (الفيزياء 2015، الكيمياء 2014، الرياضيات 2018، الإعلام)
- **Electropedia (IEC 60050)** — الموسوعة الكهربائية الدولية
- **معجم المصطلحات العلمية والفنية والهندسية الجديد** (لبنان ناشرون، 2018)
- مصطلحات البلاغة والعروض: إضافة منقّحة خاصة بالتطبيق

هذا المستودع يخدم التطبيق فقط ولا يُعد مصدراً تجارياً — حقوق النصوص الأصلية لأصحابها.
